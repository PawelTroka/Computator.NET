# Web custom functions and JSON execution

The Custom Functions page is no longer a placeholder. Its Ace editor state is shared across routes in the current tab. Unsaved definitions are sent with each execution. Explicit Save stores a versioned copy in sessionStorage; reload restores it. Import/export uses UTF-8 `.tslf` files and does not change the desktop format. Browser sessions/tabs are not a server-side account system.

`POST /api/v2/execute` accepts `{operation, expression, customFunctions, x, y, a, b, n, order, epsilon, method}`. Operations are calculate, script, integral, derivative and function-root. Results are `{result: string}` in the existing mathematical display notation. `POST /api/v2/chart` accepts expression/definitions and width, height, xMin/xMax/yMin/yMax and returns PNG. Requests are bounded and validated; malformed programs receive problem details. Programs are data in the JSON body, never path segments, so `/`, Unicode and multiline definitions survive transport.

Each request has a fresh evaluator. No generated function object, definition string or mutable compiler state is cached across callers. Legacy GET endpoints remain for compatibility and retain their documented limitations; new UI requests use v2. Response cancellation is not execution isolation: trusted scripts may do anything the host process can do. Do not expose this API publicly. Apply the protected local deployment from the separate web-E2E PR when integrating both.

Run `./build.ps1 -Target Web-CustomFunctions`. Cake runs real in-process API regressions, publishes both applications, then drives Chromium and Firefox against the actual mathematical API without mocked results. Existing focused browser tests are adapted to assert the new request bodies; their test coverage is retained. The real suite checks unsaved edits, script use, saved-tab reload, UTF-8 import/export, real chart rendering, division, and independent browser contexts.

Follow-up acceptance still includes numerical-operation UI coverage for every supported method, input-method/editor interaction, and production multi-user process isolation. A native 3D chart or symbolic-algebra web implementation is not claimed by this change. Integration with the separate proxy PR should rerun both real suites on the combined head.
